# DevCollab

DevCollab is a full-stack collaboration platform developed using the MERN stack. The application allows users to register, log in, manage profiles, collaborate on projects, and upload images using Cloudinary integration.

## Features

- User Authentication
- Secure Login & Signup
- MongoDB Database Integration
- REST API Backend
- Image Upload with Cloudinary
- Responsive Frontend UI
- Full Stack Deployment

## Technologies Used

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Deployment
- Vercel (Frontend)
- Render (Backend)

## Installation

```bash
git clone https://github.com/ravanangsoham/DevCollab-Project.git
cd DevCollab-Project
npm install
```

## Run Frontend

```bash
cd client
npm run dev
```

## Run Backend

```bash
cd server
npm start
```
